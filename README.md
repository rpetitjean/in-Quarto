# in-Quarto
A browser-based editor for eight-page in-quarto booklets.

Open the [project page](https://rpetitjean.github.io/in-Quarto/) to write or
paste text, or choose a UTF-8 plain text file to edit. Use **Download text** to
save your work. Files stay in your browser; opening another file replaces the
current text.

The current page edits plain text only; booklet layout and printing are not yet
available. To run it locally, open `index.html` in a browser.
